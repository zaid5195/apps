# إديت الشخصيات (Anime Edit) من الصور

المستخدم كيهضر بالدارجة المغربية. جاوبو بالدارجة، وخلي المصطلحات التقنية بالإنجليزية (Drop, Kick, Captions).
المرجع: إديت كيلوا زولديك اللي عجب المستخدم بزاف (`examples/killua.json`). أي إديت جديد يبدا من نسخة ديالو.

## قواعد ثابتة (من ملاحظات المستخدم)

1. **الصور خاصها تناسب الكلام.** هادي أهم حاجة قالها المستخدم ("خصك غير نختار الصور المناسبة"). كل جملة ديال الراوي عندها صورة كتعني نفس المعنى (عائلة القتلة ← صورة العائلة، "No friends" ← الشخصية بوحدها فالظلام، "free" ← سما زرقا). اكتب `_why` لكل لقطة فالـ config.
2. **حتى ضبابة (blur).** الصورة كتعمر الشاشة كاملة (cover crop) مع `focus`/`fy` على الوجه. ما كاين حتى خلفية مضببة.
3. **صور HD فقط.** استعمل `/images/hd/` (حتى 4K)، ماشي `/images/high/` (900px كتولي رطبة).
4. **صوت فخم بالإنجليزية** + ترجمة مكتوبة متحركة. الكلمات المهمة كبار وزرق وكيتهزو.
5. **ما تكترش الإفكتات.** البرق على الـ Kicks وفي اللحظات القوية فقط؛ الشرارات خفاف فالبداية (كانو كيبانو بحال الثلج).
6. **شوف بعينيك قبل ما تصيفط.** دير contact sheet ديال فريمات (Read للصورة) فكل نسخة: شي صورة كتكون مقطوعة (الشخصية فطرف الصورة)، شي كلمة كتخرج من الشاشة.

## حدود (ما تبدلهاش)
- **ما تنزلش حلقات أنمي ولا كليبات من الأنمي**، وما تصاوبش الشخصية بالذكاء الاصطناعي (صور ولا فيديو): حقوق النشر. إلا بغا فيديو حقيقي: هو يقطع الكليبات (تسجيل الشاشة) ويصيفطهم.
- **ما تنزلش أغاني معروفة** من الإنترنت. الأغنية كيصيفطها المستخدم (`/root/.claude/uploads/...`)، ولا صاوب بيت أصلي.
- الصور (fan art / official art) للاستعمال الخاص ديالو فقط: **ما تديرهاش فالـ repo**. خدم فـ scratchpad.
- B-roll بالذكاء الاصطناعي ديال الأجواء (عاصفة، برق، طاقة) مسموح، ولكن بالكريديت ديالو: قول الثمن وتسنى الموافقة.

## الخطوات

`SK=.claude/skills/anime-edit/scripts` — `WORK` = مجلد فـ scratchpad.

1. **الأغنية**: `cp` ملف المستخدم لـ `WORK/song.m4a`، ومن بعد
   `python3 $SK/analyze_song.py WORK/song.m4a --to 60 > WORK/song.json`
   كيطبع خريطة الطاقة، الـ BPM، الدروب (`drop`) والـ Kicks. شوف الخريطة: الإديت كيكون ~45–55 ث، والدروب فالنص تقريبًا (الصوت قبل الدروب، الصور السريعة بعدو). `drop_end` = Kick قبل ما تطيح الطاقة. إلا الدروب ماشي فبلاصتو، استعمل `song_start` ولا `--from`.
2. **السكريبت**: 8–9 جمل قصار بالإنجليزية، كيحكيو قصة الشخصية (الأصل ← الألم ← التحول ← الاسم). الجملة الأخيرة = اسم الشخصية وكتسالي **بالضبط** مع الدروب. الجمل القصار المهمة ("No fear.") كل وحدة بوحدها مع `speed` 0.8.
3. **الصور**: الشبكة خاصها تسمح بـ `wallpapers.com` (إلا تبلوكات: `get_environment` ثم `create_environment` شخصي، ماشي Default).
   - `python3 $SK/images.py find WORK/img --match "killua|zoldyck|gon" <slug>?p=2 <slug>?p=3 <slug>-4k ...` (الـ slugs اللي كاينين: `NAME`, `NAME?p=N`, `NAME-4k`, `NAME-aesthetic`, `NAME-phone`, `ANIME-4k`; كتعطي 404 إلا ما كاينش)
   - `python3 $SK/images.py sheet WORK/img` ← **Read لكل sheet** واختار صور كتناسب كل جملة + 7–9 صور قوية للدروب، بلا تكرار (شي صور مكررين بأسماء مختلفين).
   - `python3 $SK/images.py get WORK/img N N N ...` ← كتعطي القياس. من بعد دير sheet ديال الصور المختارة مع علامات العشر باش تحدد `focus` (x ديال الوجه 0..1) و `fy`.
4. **الـ config**: نسخ `examples/killua.json`، بدل كلشي (الصور، الجمل، الأوقات، `title`, `subtitle`, `keywords`, `name_words`, الألوان حسب الشخصية: برق أزرق لكيلوا، نار برتقالي، إلخ). `at` ديال كل جملة = فين كتبدا؛ خلي ~0.4 ث بين الجمل. اللقطات قبل الدروب: `intro` (هادي، لون مطفي)، `pan` (focus [من، إلى] — مزيان لجوج شخصيات)، `free` (ألوان طبيعية)، `flicker` (برق كيرعش)، `push` (زووم + خطوط سرعة قبل الدروب).
5. **الصوت**: `python3 $SK/voice.py WORK/config.json WORK` ← Kokoro مجاني (`am_onyx` + طبقة أخفض + echo). إلا ElevenLabs متاح وفيه كريديت: صوت تريلر ("Don - Movie Trailers"، model eleven_v4)، حط كل جملة فـ `WORK/tts/lineN.wav` وزيد `--skip-tts`. شيك المستوى: `ffmpeg -t <drop> -i WORK/vo.wav -af "volume=<gain>,volumedetect" -f null -` — الصوت خاصو يكون أعلى من الموسيقى المنخفضة (`duck`) بشي 3 dB.
6. **Preview**: `python3 $SK/render.py WORK/config.json WORK WORK/preview.mp4 --preview` (نص الحجم و 15 fps، ~2 دقايق). استخرج فريمات بـ ffmpeg فالأوقات المهمة وشوفهم (Read).
7. **النسخة النهائية**: نفس الأمر بلا `--preview` (~4 دقايق لـ 50 ث). شيك الفريمات مرة أخرى، ومن بعد `SendUserFile` مع `display: render`.

## الإديت من الداخل (render.py + fx.py)
- قبل الدروب: لون مطفي + tint موف، زووم بطيء، fade-in، شرارات خفاف بزاف.
- الدروب: فلاش أبيض + اهتزاز قوي 1.2 ث + 4 برقات. من بعد: صورة جديدة على كل Kick، زووم/اهتزاز 0.3 ث، RGB split 0.18 ث، فلاش خفيف، 2 برقات، شرارات.
- النهاية: فلاش، العنوان (سطرين + subtitle + علامة برق) فوق شريط مظلم، fade-out 1.5 ث.
- Captions: كلمة بكلمة (pop-in بـ overshoot)، الوقت ديال كل كلمة تقريبي داخل الجملة (محسوب بطول الكلمة)؛ بلا نقط وفواصل؛ الكلمات اللي فـ `keywords` كبار وبتدرج أبيض←لون الـ accent ومهتزين.
- Grain خفيف على كلشي.

## أفكار للتطوير (إلا طلبها)
- B-roll ديال البرق/الطاقة بالذكاء الاصطناعي كـ overlay (Higgsfield / Halai، بالكريديت).
- كليبات المستخدم: زيدها كـ shots فالـ config (يحتاج تعديل `src` باش يقرا فيديو).
- Captions بالعربية: خاص خط عربي + `arabic_reshaper`/`python-bidi`.
