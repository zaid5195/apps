# Reel Studio v1 🎬

Reel Studio يحوّل **موضوع** إلى ريل عمودي جاهز (1080×1920). الريل شرح علمي بدون وجه، باللهجة المصرية، على طريقة سلسلة «عارف ليه؟».

## 🧩 الواجهة: زي n8n
- كل ريل عبارة عن **workflow** على لوحة منقّطة:
  - الخطوات: الموضوع ← السكريبت ← الصوت ← التوقيت ← الستوري بورد ← الرندر ← النشر.
  - تحت الخطوات فيه **عُقد فرعية** للموديل ومزوّد الصوت والشكل.
- **ألوان العقدة:** برتقالي متحرك = شغّال، أصفر = بانتظار موافقتك، أخضر = خلص، أحمر = خطأ. والخطوط بتتحرك مع التشغيل.
- **اضغط أي عقدة** تفتح لوحتها: النتيجة، التعديل، السجل، «أعد الخطوة»، تلقائي أو استناني.
- **التحكم في اللوحة:** سحب للتحريك، وعجلة الماوس أو إصبعين للتكبير، وزر ملاءمة.
- **على الهاتف** الـworkflow بينزل من فوق لتحت، واللوحات بتطلع من تحت.

## ✨ المزايا
- **موسيقى خلفية أصلية:** فيه 3 أجواء (هادئ، تشويق، حماسي)، والموسيقى بتوطى لوحدها لما المعلّق بيتكلم. معمولة جوه البرنامج، فمفيش مشاكل حقوق.
- **بداية خاطفة:** الجملة الأولى بتظهر بخط كبير، وكل كلمة بتطلع في نفس لحظة نطقها.
- **3 أشكال للترجمة:** عادي، أو كلمة كبيرة في النص، أو صندوق ملوّن ماشي مع الكلمة. الأرقام بتتلوّن لوحدها.
- **شاشة النهاية:** فيها «تابعني» واسم حسابك، وسؤال للتعليقات.
  - الاسم والسطرين بتغيّرهم من «🎨 الشكل» في كل مشروع، أو من الإعدادات كافتراضي.
- **3 مقاسات:** 9:16 و1:1 و16:9 من نفس المشروع.
- **غلاف (cover.jpg)** بيتعمل لوحده.
- **وصف وهاشتاغات** جاهزين للنسخ بضغطة.
- **تعديل المشاهد باللمس:** النوع والقالب والأيقونة والنصوص، من غير JSON.
- **💡 اقتراح 10 مواضيع**، و**📋 بزاف ديال الريلز مرة وحدة** (طابور بيشتغل لوحده).
- **صوت مجاني بـ Gemini TTS** بنفس مفتاح Gemini:
  - لو عندك مفتاح ElevenLabs أو Deepgram، التوقيت بيبقى دقيق.
  - من غيرهم، التوقيت بيتحسب تقريبيًا من الصوت.

## 🔁 مزوّدين احتياطيين للذكاء الاصطناعي
- في الإعدادات تقدر تضيف مزوّدين تانيين، كل واحد بمفتاحه وبالترتيب اللي تختاره:
  - فيهم خطة مجانية: Groq، OpenRouter، Cerebras، Mistral، GitHub Models، NVIDIA NIM، SambaNova، Together.
  - مدفوعين: DeepSeek، OpenAI.
  - أو أي مزوّد تاني متوافق مع OpenAI.
- لو الأساسي فشل، أو كان مزحوم، أو خلص الحد المجاني، البرنامج بيجرّب اللي بعده لوحده.
- زر ⟳ بيجيب الموديلات المتاحة عند كل مزوّد.

## 🌍 اللغات
- كل مشروع تختار له لغة الفيديو: **العربية المصرية** («عارف ليه؟») أو **الإسبانية** («¿Sabes por qué?»).
- مع الإسباني بيتغيّر كل حاجة لوحدها:
  - السكريبت بأسلوب السلسلة، وأسلوبه في `references/script-style.es.md`.
  - السرعة حوالي 2.8 كلمة في الثانية.
  - التوقيت بيستعمل Deepgram `es` وScribe `spa`.
  - الترجمة على الشاشة والقوالب بتتقلب من الشمال لليمين.
  - اسم السلسلة بالإسباني بتغيّره من الإعدادات.
- واجهة البرنامج نفسها بتفضل بالعربي.

المراحل خمسة: **سكريبت ← صوت ← توقيت ← ستوري بورد ← رندر**.
- كل مرحلة فيها سجل مباشر.
- لكل مرحلة تختار «تلقائي» أو «استناني» لحد ما توافق.
- تقدر تعيد أي مرحلة أو تعدّلها أو تلغيها.

## طريقتين للتشغيل

### 📱 على الهاتف، بدون كمبيوتر
افتح: **https://zaid5195.github.io/apps/reel-studio/**
(تفتح بعد دمج التغييرات في الفرع الرئيسي.)

- كل حاجة بتشتغل جوه متصفح Chrome على الهاتف:
  - المشاريع محفوظة على الجهاز نفسه.
  - الرندر بـ WebCodecs (تسريع عتادي).
  - مفيش سيرفر.
- من قائمة Chrome اختار «إضافة إلى الشاشة الرئيسية»، فيشتغل زي التطبيق.
- خلي الصفحة مفتوحة والشاشة شغالة لحد ما الرندر يخلص.
- الإعدادات الافتراضية على الهاتف: Gemini للكتابة، وElevenLabs Scribe لتوقيت الصوت المرفوع. تقدر تغيّرها، أو تختار Groq أو OpenRouter بضغطة.

### 💻 على الكمبيوتر
1. لازم يكون عندك Node.js 18 أو أحدث.
2. على Windows: افتح **`start.bat`**.
   - أول مرة يعمل التثبيت لوحده (`npm run setup`)، وبعدين يفتح المتصفح على http://127.0.0.1:4301
3. على Mac أو Linux: `./start.sh`
4. على Android مع Termux: `./start-termux.sh`
   - السيرفر بيشتغل على الهاتف، والرندر بيحصل في تبويب Chrome.

الرندر على الكمبيوتر:
- Chromium (Playwright) بيرسم كل فريم، وffmpeg بيعمل H.264 (yuv420p) والصوت بـ AAC.
- لو Chromium مش موجود، بيستخدم Chrome المثبّت، أو بيرندر في المتصفح.

## المفاتيح (من شاشة الإعدادات)

| الخدمة | لإيه | منين |
|---|---|---|
| FreeLLMAPI أو أي API متوافق مع OpenAI | السكريبت والستوري بورد | https://github.com/tashfeenahmed/freellmapi (الافتراضي `http://127.0.0.1:31415/v1` والموديل `auto`) |
| ElevenLabs | الصوت، ومعاه توقيت كل حرف | https://elevenlabs.io/app/developers/ |
| Deepgram | توقيت الصوت اللي ترفعه انت | https://console.deepgram.com/ |

- المفاتيح بتتحفظ في `data/settings.json`، والمتصفح بيشوف آخر 4 حروف بس.
- تقدر تحطها كمان في ملف `.env` (شوف `.env.example`).
- السيرفر بيسمع على 127.0.0.1 بس، وبيرفض أي طلب جاي من موقع تاني.

## تعديل الأسلوب والشكل
- أسلوب السلسلة كله في `references/script-style.md`.
- الألوان والقوالب في `public/render/engine.js`.
- الخط: IBM Plex Sans Arabic (رخصة OFL، الملف `public/assets/fonts/OFL.txt`). تقدر تغيّره من «فولدر الخط» في الإعدادات.
- الأيقونات في ملف واحد `public/assets/icons/icons.json` ومعاها تراخيصها:
  - رسم يدوي (CC0)
  - Health Icons (CC0)
  - Tabler (MIT)
  - لإعادة بنائه: `npm run icons`

## الاختبارات (كلها بدون إنترنت)

```
npm test                     # اختبارات الوحدات
node tools/mock-apis.mjs     # FreeLLMAPI + ElevenLabs + Deepgram وهميين على :4399
npm run e2e                  # ريل 10 ثواني كامل + فحص المزامنة والصوت (−14 LUFS)
node tools/e2e.mjs --lang es # نفس الاختبار بالإسباني
node tools/e2e.mjs --upload  # نفس الاختبار بصوت مرفوع (Deepgram)
npm run sheets               # مشروع لكل قالب + كونتاكت شيت في data/sheets/ (أضف --es للإسباني)
node tools/ui-test.mjs       # الواجهة على مقاس الهاتف، وضع السيرفر ووضع الهاتف
```

كل روابط الـ APIs تقدر تغيّرها بمتغيرات البيئة: `LLM_BASE_URL`، `ELEVENLABS_BASE_URL`، `DEEPGRAM_BASE_URL`.

> ملحوظة: الفيديو اللي بيترندر في المتصفح صوته AAC لو المتصفح بيدعمه (Chrome على Android وWindows). لو مش بيدعمه، الصوت بيبقى Opus. لو منصة رفضت الملف، رندر الفيديو من الكمبيوتر.
