ترجم فصل المانهوا داخل الفقاعات

ارفع صور الفصل أو ملف ZIP (مثل اللي تنزّله إضافة «منزّل المانهوا»). الموقع يمسح الكلام الأصلي ويكتب الترجمة داخل كل فقاعة، ويحفظ أسماء الشخصيات لكل مانهوا.

⚙️ الإعداد

كيف آخذ مفتاح مجاني؟ (دقيقة وحدة)
  1. افتح aistudio.google.com/apikey وسجّل بحساب Google.
  2. اضغط Create API key وانسخ المفتاح.
  3. الصقه هنا. ينحفظ في متصفحك بس، وما يروح إلا لـ Google.
📚 السلسلة والأسماء
الأسماء المحفوظة تنستعمل في كل فصل من نفس المانهوا. لو غيّرت ترجمة اسم، تتغيّر في الصفحات المترجمة كمان. الأصفر = انضاف تلقائياً.
