🎛️ لوحة التحكم

تحكّم في تطبيقاتك من هنا — التغيير يوصل للناس خلال دقائق بدون تحديث.

🔑 الدخول (مرة وحدة بس)

اللوحة تحتاج «مفتاح دخول» من GitHub عشان تقدر تعدّل إعدادات تطبيقاتك. المفتاح يبقى في متصفح جوالك بس، وما يقدر أحد غيرك يستخدم اللوحة بدونه.

  1. افتح صفحة إنشاء المفتاح في GitHub.
  2. في Token name اكتب: control-panel
  3. في Expiration اختر مدة طويلة (مثلاً 1 year).
  4. في Repository access اختر Only select repositories ثم اختر apps.
  5. في Permissions ← Repository permissions ← Contents اختر Read and write.
  6. انزل تحت واضغط Generate token، وانسخ المفتاح (يبدأ بـ github_pat_).
  7. الصقه هنا واضغط دخول.
