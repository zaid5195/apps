# تطبيقات المتابعين 📱

موقع التطبيقات: **https://zaid5195.github.io/apps/**

تقترح التطبيق… نسويه بالذكاء الاصطناعي… وتحمّله مجانًا.

## طريقة العمل (للصيانة)
- `site/apps.json`: قائمة التطبيقات (الاسم، الوصف، المزايا، رابط التحميل، صاحب الفكرة…).
- `site/build.mjs`: يبني الصفحة الرئيسية وصفحة لكل تطبيق (`node site/build.mjs`).
- ملفات التطبيقات: كل نسخة «إصدار» (Release) في هذا المستودع باسم `<slug>-v<رقم>`، ينشره المصنع تلقائيًا. GitHub يحسب تحميلات كل ملف، ومنها تقرأ لوحة التحكم العدد.
- تطبيق بدون `download` في `site/apps.json` = «قريباً» (يطلع في الموقع بدون زر تحميل).
- كل دفع إلى `main` ينشر الموقع تلقائيًا على فرع `gh-pages`. بعد تحديث `apk-files` شغّل «Publish website» يدويًا من Actions.

## 🎛️ لوحة التحكم في التطبيقات (من جوالك)
**الأسهل:** افتح https://zaid5195.github.io/apps/admin/ — أزرار تشغيل/إيقاف بدون كتابة، عدد التحميلات لكل تطبيق ولكل نسخة، رسالة لكل التطبيقات مرة وحدة، تعديل صفحة كل تطبيق (صاحب الفكرة، رابط الفيديو…)، وإضافة تطبيقات «قريباً». أول مرة تحتاج «مفتاح دخول» من GitHub (الخطوات مكتوبة في الصفحة). مزايا كل تطبيق اللي تطلع في اللوحة تنكتب في `controls` داخل `site/apps.json`.

أو عدّل الملف يدويًا:
لكل تطبيق ملف تحكم: `site/config/<اسم-التطبيق>.json` (مثال: `site/config/floating-translator.json`).
افتحه في GitHub ← اضغط ✏️ (Edit) ← غيّر القيمة ← **Commit changes**. يوصل التغيير للتطبيق عند الناس خلال دقائق، بدون تحديث.

| الخانة | وش تسوي | مثال |
|---|---|---|
| `maintenance` | `true` يوقف التطبيق ويطلع رسالة صيانة. رجّعها `false` لما تخلص | `true` |
| `maintenanceMessage` | نص رسالة الصيانة (اختياري) | `"نرجع بعد ساعة 🛠️"` |
| `minVersionCode` | أي نسخة أقدم من هذا الرقم تُجبر على التحديث | `5` |
| `latestVersionCode` | رقم آخر نسخة — الأقدم منها يطلع لهم «نسخة جديدة متاحة» | `6` |
| `message.id` + `message.text` | رسالة تطلع مرة وحدة لكل مستخدم. غيّر `id` لكل رسالة جديدة | `"id": "tiktok-1"` |
| `message.url` | رابط اختياري مع الرسالة (زر «فتح») | رابط فيديو |
| `disabledFeatures` | توقف ميزة وحدة بس: `"ai"` (الترجمة الذكية)، `"bubble"` (الفقاعة)، `"select_text"` (الترجمة من تحديد النص) | `["ai"]` |

⚠️ انتبه للفواصل وعلامات التنصيص — إذا انكسر الملف يفشل النشر ويبقى آخر إعداد سليم شغّال.
